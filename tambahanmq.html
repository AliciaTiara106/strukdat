Merge & Quick Sort

Merge Sort:
Mekanisme Rekursif: Pembagian menggunakan pola L (Left) dan R (Right).
Proses Merge: Mencakup perhitungan langkah penggabungan (Merge 1, Merge 2, dst.) dari level sub-array terkecil hingga kembali utuh.

Implementasi Python:

python 
def merge_sort_analisis(arr, level=0):
    # Menghitung jumlah rekursi
    count_rec = 1
    count_comp = 0
    
    if len(arr) <= 1:
        return arr, count_rec, 0

    mid = len(arr) // 2
    # L..... R.....
    left_half = arr[:mid]
    right_half = arr[mid:]
    
    print(f"Rekursif level {level}: Membagi {arr} -> L:{left_half} R:{right_half}")

    left_sorted, rec_l, comp_l = merge_sort_analisis(left_half, level + 1)
    right_sorted, rec_r, comp_r = merge_sort_analisis(right_half, level + 1)
    
    count_rec += rec_l + rec_r
    
    # Proses Merge
    merged, merge_comp = merge(left_sorted, right_sorted)
    count_comp = comp_l + comp_r + merge_comp
    
    print(f"Merge level {level}: {left_sorted} + {right_sorted} -> {merged}")
    
    return merged, count_rec, count_comp

def merge(left, right):
    result = []
    i = j = 0
    comp = 0
    while i < len(left) and j < len(right):
        comp += 1
        if left[i] < right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result, comp
Quick Sort:
Quick Sort & Analisis Pivot:
Pengaruh Pivot: Analisis performa berdasarkan pemilihan posisi pivot (Depan, Belakang, Tengah). Pivot tengah umumnya lebih efisien dalam membagi beban rekursif.
Efisiensi: Catatan mencakup hubungan antara pemilihan pivot dengan jumlah rekursi yang terjadi serta jumlah perbandingan data (kompleksitas O(n log n) vs O(n^2)).

Implementasi Python:

python 
def quick_sort_analisis(arr):
    stats = {"recursion": 0, "comparisons": 0}

    def sort(sub_arr):
        stats["recursion"] += 1
        if len(sub_arr) <= 1:
            return sub_arr

        # Menggunakan pivot tengah
        pivot_idx = len(sub_arr) // 2
        pivot = sub_arr[pivot_idx]
        
        left = []
        middle = []
        right = []

        for x in sub_arr:
            stats["comparisons"] += 1 # Setiap elemen dibandingkan dengan pivot
            if x < pivot:
                left.append(x)
            elif x > pivot:
                right.append(x)
            else:
                middle.append(x)

        # Rekursi depan (left) dan belakang (right)
        return sort(left) + middle + sort(right)

    result = sort(arr)
    return result, stats["recursion"], stats["comparisons"]
