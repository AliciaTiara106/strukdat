pengerian infix, postfix, dan prefix

Infix, Prefix, dan Postfix adalah tiga cara berbeda untuk menuliskan ekspresi matematika berdasarkan posisi operatornya (seperti +, -, *, /)
1) Infix (Notasi Umum): Operator diletakkan di antara angka atau variabel.
ex = A + B
2) Prefix (Notasi Polandia): Operator diletakkan di depan angka atau variabel.
ex = +AB
3) Postfix (Notasi Reverse Polish): Operator diletakkan di belakang angka atau variabel.
ex = AB+
- Aturan Presedensi (Precedence Rules)
Ini adalah aturan "siapa yang lebih kuat" atau mana yang harus dihitung duluan dalam matematika (sering disebut KBATAKU)
-> Paling Tinggi: Tanda kurung ()
-> Tinggi: Pangkat **
-> Menengah: Perkalian *, Pembagian /, Sisa Bagi %
-> Rendah: Penjumlahan +, Pengurangan -
-> Paling Rendah: Operator logika seperti not, and, or
Jika ada operator dengan kekuatan yang sama, hitung dari Kiri ke Kanan

Infix to Postfix

Proses mengubah cara tulis biasa menjadi cara tulis komputer menggunakan bantuan Stack (tumpukan).Operand Angka/Huruf langsung dimasukkan ke hasil akhir. Operator dimasukkan ke tumpukan (stack), tapi jika di dalam tumpukan sudah ada operator yang lebih kuat atau sama kuatnya, keluarkan dulu yang lama, baru masukkan yang baru.

contoh :

Infix: A*B+C-D/E
Postfix : AB*C+DE/-

soal = input("Masukkan Infix: ")

soal_list = list(soal[::-1])
for i in range(len(soal_list)):
    if soal_list[i] == '(': soal_list[i] = ')'
    elif soal_list[i] == ')': soal_list[i] = '('
soal_balik = "".join(soal_list)

stack_pre = []
hasil_pre = []
kuat = {'+': 1, '-': 1, '*': 2, '/': 2, '^': 3, '(': 0}

for k in soal_balik:
    if k.isalnum():
        hasil_pre.append(k)
    elif k == '(':
        stack_pre.append(k)
    elif k == ')':
        while stack_pre and stack_pre[-1] != '(':
            hasil_pre.append(stack_pre.pop())
        if stack_pre: stack_pre.pop()
    else:
        while stack_pre and kuat[k] < kuat.get(stack_pre[-1], 0):
            hasil_pre.append(stack_pre.pop())
        stack_pre.append(k)

while stack_pre:
    hasil_pre.append(stack_pre.pop())

prefix = "".join(hasil_pre)[::-1]

stack_post = []
hasil_post = []

for k in soal:

        hasil_post.append(k)

def infixToPostfix(contoh):
  prioritas = {'*': 3, '/': 3, '+': 2, '-': 2}
  stack = []
  postfix = ""

  for char in contoh:
    if char == '(':
      stack.append(char)
    elif char == ')':
      while stack[-1] != '(':
        postfix += stack.pop()
      stack.pop()
    elif char in "+-*/":
      while stack and prioritas[stack[-1]] >= prioritas[char]:
        postfix += stack.pop()
      stack.append(char)
    else:
      postfix += char
  while stack:
    postfix += stack.pop()
  return postfix

ekspresi = input("infix: ")
print("Postfix :", infixToPostfix(ekspresi))
